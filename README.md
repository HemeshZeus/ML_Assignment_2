# ML Classification Project — Assignment 2

## a. Problem Statement

The goal of this project is to build, evaluate, and deploy multiple supervised
machine learning classification models that predict whether a tumor is
**malignant or benign** based on a set of numeric diagnostic features derived
from digitized images of a breast mass. This is framed as a **binary
classification** problem, and the objective is to compare several classical
ML algorithms on the same dataset using a consistent set of evaluation
metrics, then expose the trained models through an interactive Streamlit
web application.

## b. Dataset Description

- **Dataset:** Breast Cancer Wisconsin (Diagnostic) Dataset
- **Source:** `sklearn.datasets.load_breast_cancer` (originally from the UCI
  Machine Learning Repository)
- **Instances:** 569 (satisfies the minimum instance requirement of 500)
- **Features:** 30 numeric features (satisfies the minimum feature
  requirement of 12) — computed from digitized images of fine needle
  aspirates (FNA) of breast masses, e.g. `mean radius`, `mean texture`,
  `mean perimeter`, `mean area`, `mean smoothness`, etc.
- **Target variable:** Binary — `0 = malignant`, `1 = benign`
- **Class balance:** ~37% malignant, ~63% benign
- **Train/Test split:** 80% train / 20% test, stratified on the target label

### Observations

| ML Model Name              | Observation about model performance |
|------------------------------|--------------------------------------|
| Logistic Regression          | Performed the best overall despite being the simplest model. The classes are close to linearly separable after scaling, so a linear decision boundary generalizes very well. Highest AUC and MCC of all models, with virtually no overfitting between train and test scores. |
| Decision Tree                | Weakest performer of the five. A single unpruned tree overfits the training data and is highly sensitive to small variations in feature splits, which hurts generalization — reflected in the lowest accuracy, AUC, and MCC. |
| kNN                           | Strong performer with high recall, meaning it rarely misses malignant cases in this framing. Sensitive to feature scaling (handled here via `StandardScaler`) and to the choice of `k`; performance would degrade on higher-dimensional or noisier data. |
| Naive Bayes                   | Solid, fast baseline despite its strong (and technically incorrect) feature-independence assumption — the correlated features don't hurt it as much as expected. Slightly lower precision than the top models, indicating a few more false positives. |
| Random Forest (Ensemble)      | Very close second to Logistic Regression. Averaging many decorrelated trees substantially reduces the overfitting seen in the single Decision Tree and yields high, stable accuracy, recall, and AUC with low variance. |
| **Overall Winner for your dataset?** | **Logistic Regression** — it achieved the highest Accuracy, AUC, F1, and MCC, and it is also the most interpretable and cheapest model to serve in production, making it the best overall choice for this dataset. |

## How to Run Locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train all models (creates model/*.joblib and test_data.csv)
python train_models.py

# 3. Launch the Streamlit app
streamlit run app.py
```
